# 📂 Modern File Handler

A simple, responsive, and intuitive local file management application built using Python. This project features both a classic Command Line Interface (CLI) and a modern, tab-based Web UI.

## ✨ Features
- **Create**: Quickly generate new text files with customized content.
- **Read**: View the content of existing local files seamlessly.
- **Update**: Append or modify content within your files easily.
- **Delete**: Safely remove files from your local directory.

## 📁 Repository Structure
- `main.py`: Contains the core file-handling logic and the original terminal/CLI version of the application.
- `app.py`: The enhanced, interactive Web UI version built using Streamlit.

## 🚀 How to Run the App

### Prerequisites
Make sure you have Python installed on your system. You will also need to install Streamlit:

`pip install streamlit`

### Running the Web UI
To launch the modern Streamlit user interface, run the following command in your terminal:

`streamlit run app.py`

## 🛠️ Built With

- **Streamlit** - For building the responsive, modern frontend UI.
